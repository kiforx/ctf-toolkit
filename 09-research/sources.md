# Research: Джерела та статус перевірки

**Для чого:** звідки взято методи, що перевірено практично, а що — ні.
← [README](../README.md)

---

## Методологія
Документація зібрана під профіль цього CTF (з `SG test.pdf`):
**модифікований KotH, root не потрібен, багато пост-експлойту, прапорці розкидані.**
Акцент — enumeration → credential reuse → латеральний рух → flag-hunt, а не priv-esc до root.

Техніки — узагальнення повторюваних патернів easy/medium машин (HTB/TryHackMe) та типових
misconfiguration, без переказу конкретних writeup-ів.

## Статус перевірки
| Що | Статус |
|---|---|
| Факти про формат/правила/VPN | з офіційного `SG test.pdf` |
| Формат прапорця: сепаратори `-` `_` `.`, тіло `{[[:alnum:]_]+}`, хвіст `:N` | звірено з реальними зразками |
| [flagscan.sh](../05-scripts/flagscan.sh) (автор — тімейт) | перевірено: ловить усі 21 наданий зразок, дедуп, фільтри, пропуск бінарних |
| Синтаксис усіх скриптів | `bash -n` OK |
| Команди nmap/curl/grep/find/ffuf/smb тощо | стандартний синтаксис; **не** запускались проти живої цілі |
| Reverse shells / payload-и | класичні робочі шаблони; IP/порт/оточення підлаштувати на місці |
| Техніки (SUID/cron/LFI/SQLi/…) | узагальнені методи; конкретика залежить від цілі |
| Тривалість 5 год / 3–4 гравці | з вихідного завдання, **не** з офіційного PDF (тест був 1 год) |

## Припущення щодо основного етапу (НЕ факти)
- Формат прапорця може відрізнятись → `FLAG_REGEX`/`NOISE` у скрипті легко змінити.
- «Без рута» підтверджено лише для тесту.
- Склад сервісів/ОС невідомий; Windows — під питанням (тест схожий на Linux).

## Зовнішні довідники (завантажити офлайн до гри)
Не єдине джерело істини — лише доповнення; усе ключове продубльовано в репо.
| Ресурс | Для чого |
|---|---|
| GTFOBins | зловживання sudo/SUID-бінарями |
| PayloadsAllTheThings | payload-и LFI/SQLi/revshell/SSRF |
| revshells (генератор) | швидкі reverse-shell рядки |
| HackTricks | загальна методологія enum/post-ex |
| exploit-db / searchsploit | офлайн-база експлойтів (вже в Kali) |

## Обмеження документації
- Не перевірялось проти реальної ігрової машини (її ще немає).
- Не покриває глибокий root-priv-esc, бінарну експлуатацію, повний AD — свідомо (поза профілем/рівнем).
- Команди орієнтовані на Kali.
