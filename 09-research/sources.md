# Research: Джерела та статус перевірки

**Для чого:** звідки взято методи, що перевірено практично, а що — ні.
← [README](../README.md)

## Методологія
Документація зібрана під профіль основного етапу (з `SG main.pdf`):
**KotH, ціль — root + `king.txt`, прапорці по дорозі, патчинг своєї машини.**
Акцент — recon → вхід → **privilege escalation до root** → king.txt + патч; flag-hunt на кожному рівні.

Техніки — узагальнення повторюваних патернів easy/medium машин (HTB/TryHackMe) та типових
misconfiguration, без переказу конкретних writeup-ів.

## Статус перевірки
| Що | Статус |
|---|---|
| Факти про формат/правила/ціль/VPN | з офіційного `SG main.pdf` |
| Формат прапорця: шум `[-_.]`, тіло `{...}`, суфікс `:<буква><номер>`; здавати `bestCTF{FLAG}` | з `SG main.pdf` |
| [flag-encode.sh](../05-scripts/flag-encode.sh) (нормалізація у `bestCTF{FLAG}`) | перевірено на прикладах |
| [flags_searcher_obf.sh](../05-scripts/flags_searcher_obf.sh) | розкрито й перевірено на ізольованій машині: це `flagsearch 2.0` (find+grep),|
| Синтаксис решти скриптів | `bash -n` OK |
| Команди nmap/curl/grep/find/ffuf/smb/priv-esc тощо | стандартний синтаксис; **не** запускались проти живої цілі |
| Reverse shells / payload-и / escapes | класичні робочі шаблони; IP/порт/оточення підлаштувати на місці |

## Невідоме / уточнити на місці
- Точний шлях `king.txt`, який читає платформа (у доках — плейсхолдер `/king.txt`).
- Склад сервісів/ОС цілі; Windows — під питанням (тест був Linux-орієнтований).
- (вирішено) Обфускований searcher: `--key ФАЙЛ --directory ДИР` (space-форма), ключ `S@mEvEryC0olk3Y1414$`.

## Зовнішні довідники (завантажити офлайн до гри)
Не єдине джерело істини — лише доповнення; усе ключове продубльовано в репо.
| Ресурс | Для чого |
|---|---|
| GTFOBins | зловживання sudo/SUID-бінарями |
| PayloadsAllTheThings | payload-и LFI/SQLi/revshell/SSRF |
| revshells (генератор) | швидкі reverse-shell рядки |

## Обмеження документації
- Не перевірялось проти реальної ігрової машини (її ще немає).
- Не містить командної стратегії (розподіл часу/ролей) — команда обговорює окремо.
- Не покриває бінарну експлуатацію (pwn) — свідомо (поза рівнем).
- Windows — тепер окремий розгорнутий напрям ([windows/](../windows/README.md)): enum/privesc/credentials/AD/lateral, інструменти з SHA-256 у [tools](../tools/README.md). Команди — стандартний синтаксис (impacket/netexec/evil-winrm/PowerShell), звірений з офіційною документацією та HackTricks; **проти живої Windows-цілі не запускались**.
- Команди орієнтовані на Kali.
