# KotH: Операційний Checklist

**Для чого:** дисципліна під час гри — не втратити бали через дрібниці й не порушити правила.

## Старт (перші 10 хв)
- [ ] VPN піднятий: `sudo wg show` → `latest handshake`
- [ ] `ip a` показує `10.8.N.x`
- [ ] `ping -c2 10.0.N0.10` відповідає
- [ ] Listener-перевірка: reverse shell прийде на VPN-адресу (не localhost)
- [ ] Tracker відкритий і спільний для команди
- [ ] Ролі розподілені ([team-roles](team-roles.md))
- [ ] Повний скан портів запущено у фоні

## Під час роботи (повторювати)
- [ ] Кожен порт/кред/прапорець → одразу в tracker
- [ ] Знайдені креди → перевірити reuse на всіх сервісах
- [ ] Новий доступ → re-scan localhost + flag-hunt тут-таки
- [ ] Таймбокс на вектор ~20–25 хв → не йде → позначити rabbit hole, переключитись
- [ ] Кожні ~30 хв — 1-хв синхронізація команди

## Перед здачею прапорця
- [ ] Нормалізовані сепаратори (повний токен, як вимагає поле)
- [ ] Правильний **номер** → у правильне поле платформи
- [ ] Не приклад/не тестовий зразок (перевірити контекст)
- [ ] Записано в tracker + позначено «submitted»

## ⏱ Останні 15 хв
- [ ] Нічого нового не починаємо
- [ ] Усі знайдені прапорці здані під номерами
- [ ] Перевірити tracker: чи не забули щось здати
- [ ] Прибрати за собою зайве (relay-порти, тимчасові файли), нічого не ламати

## Заборонено (ручна перевірка організаторами!)
- [ ] DoS / флуд / брутфорс платформи
- [ ] Вимикати машину, видаляти сервіси / системні файли / **прапорці**
- [ ] Блокувати інших учасників (фаєрвол)
- [ ] Атакувати щось крім своєї цілі (`10.0.N0.10`)
- [ ] AI-асистенти під час гри
- [ ] Ділитися прапорцями/рішеннями з іншими командами
- [ ] Знайдений баг платформи → написати організаторам, не ламати

## Якщо щось відвалилось
- VPN впав → `sudo wg-quick down/up ./bestctf26.conf`, оновити сторінку
- SSH/файли зависають → MTU `1380 → 1280` ([vpn](../00-setup/vpn-wireguard.md))
- Ціль не пінгується → перевірити підмережу N, `-Pn` у nmap
- Shell не приходить → listener на VPN-адресі, payload з правильним IP
