# Setup: WireGuard VPN

> Факти нижче — з офіційного `SG test.pdf`.

---

## Встановлення
```bash
# Kali / Debian / Ubuntu
sudo apt install wireguard resolvconf
```

## Підключення / відключення
```bash
sudo wg-quick up ./bestctf26.conf
sudo wg-quick down ./bestctf26.conf
```

## Перевірка з'єднання
```bash
sudo wg show          # має бути рядок "latest handshake" — інакше тунель не піднявся
ip a                  # має з'явитись адреса 10.8.N.x
ping 10.0.N0.10       # ціль відповідає (якщо вже запущена)
```
`N` — номер підмережі учасника: для `10.8.1.x` ціль `10.0.10.10`, для `10.8.2.x` — `10.0.20.10` і т.д.

## Типові проблеми (з PDF)
| Симптом | Рішення |
|---|---|
| `resolvconf: command not found` | встанови `resolvconf` / `openresolv` |
| після VPN відпали сайти/SSH | оновити сторінку або перепідключитись |
| SSH зависає / файли не передаються | у конфігу `MTU = 1380` → `MTU = 1280`, перепідключитись |
| немає `latest handshake` | тунель не піднявся — перевірити конфіг/мережу |
| нічого не допомогло | написати організаторам: команда + адреса `10.8.N.x` + текст помилки |
